# 러닝클루 홈페이지

- 공개 방식: GitHub Pages (무료) → 도메인 www.learningclue.co.kr 연결 예정
- 관리: Claude가 파일을 고쳐 올림. 대표님은 문구 · 사진 · 숫자만 알려 주시면 됨
- 구성안: `../[문서] 자동화시스템 개발기록/04_플랫폼화 기획/2026-11-18_홈페이지_새구성안_v0.1.md`

## 파일

| 파일 | 내용 |
|---|---|
| index.html | 한 페이지 홈페이지(회사 소개 · 교육 과정 · 수행 사례 · 강사진 · 교육 문의) |
| style.css | 디자인 — 색은 디자인시스템 v0.2 토큰 |
| assets/ | 로고(흰 바탕용 dark, 어두운 바탕용 white) |

## 연결된 주소

- 강사 지원 버튼 → 교육운영 웹앱 `…/exec?page=apply` (배포 ID 고정, 바꾸지 말 것)

## 공개 전 확인할 것

- 숫자(17년 · 180명+ · 70일+), 대표 전화 · 이메일, 카카오톡 채널 주소
- 수행 사례 · 고객사 이름 공개 동의
- 회사소개서 PDF (아임웹에서 받아 assets/에 넣기)

## 공개하는 날

1. GitHub 저장소에 올리고 Pages 켜기, `CNAME` 파일에 www.learningclue.co.kr
2. 호스트코코아 DNS: www → `<계정>.github.io` (CNAME), 루트 도메인 → GitHub Pages IP 4개(A 레코드)
3. 열리는 것 확인 후 아임웹 해지
